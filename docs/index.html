What it does

Investigate → Plan → Approve → Act

An LLM-driven loop where every system mutation passes an operator approval gate before it runs.

Deny-by-default policy engine

Actions not explicitly allowed are refused — the agent can look everywhere but touch only what you grant.

Hash-chained audit log

Every step is recorded in a tamper-evident chain, so the operation can be replayed and judged by its evidence.
